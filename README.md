# Опис знімка · ЛОР

Форма для складання протоколів рентгенологічних досліджень ЛОР-органів.
Лікар позначає знахідки — програма збирає з них зв'язний опис і висновок,
друкує бланк А4 або зберігає готовий `.docx`.

Усе працює у браузері: ні сервера, ні бази, ні жодного запиту назовні.
Файли можна просто відкрити з диска (подвійний клік по `index.html`)
або покласти на GitHub Pages.

## Файли

| Файл | Що всередині |
|---|---|
| `index.html` | розмітка сторінки |
| `app.css` | оформлення, зокрема стилі друку бланка |
| `app.js` | логіка: позначки, збірка тексту, друк, експорт |
| `docxgen.js` | генератор `.docx` (мінімальний ZIP + OOXML, без бібліотек) |
| `data-phrases.js` | **довідник описових фраз** |
| `data-diagnoses.js` | **довідник висновків (діагнозів)** |

Правити зазвичай потрібно лише два останні файли. Формат полів описано
коментарем на початку кожного з них.

## Як додати або змінити фразу

Відкрийте `data-phrases.js`, скопіюйте будь-який рядок, змініть текст:

```js
{"block":"04. Верхньощелепні пазухи","group":"Рідина",
 "text":"Горизонтальний рівень рідини у верхньощелепній пазусі {S}.",
 "side":true,"p1":"","p2":"","conclusion":"гострий ексудативний гайморит {S}","mod":"Rg,КТ"},
```

Підстановки в тексті:

- `{S}` — сторона, обирається зі списку;
- `{N1}`, `{N2}` — поля для чисел (товщина, діаметр, номер зуба); підказка
  береться з `p1` / `p2`.

Кома в кінці рядка обов'язкова. Новий розділ треба спершу додати в `window.BLOCKS`
— порядок розділів там задає і порядок речень в описі.

## Як влаштований висновок

`data-diagnoses.js` зберігає формулювання **у родовому відмінку без слова «Ознаки»** —
програма додасть його сама і склеїть обране через кому:

```
Ознаки: лівобічного гемісинуситу, поліпозного пансинуситу, кістогранульоми зуба 26.
```

Поле `sides` вибирає потрібний список сторін:

- `"adj"` — прикметник **перед** словом: правобічного / лівобічного / двобічного
  (для синуситів, отитів, мастоїдитів);
- `"adv"` — обставина **після** слова: справа / зліва / з обох боків
  (для кіст, утворень, переломів);
- `""` — сторона не потрібна.

`raw: true` означає готове самостійне речення (норма, динаміка, рекомендації) —
таке не входить у перелік «Ознаки:», а додається після нього.

Якщо на вкладці «Висновок» не позначено нічого, висновок збереться автоматично
з поля `conclusion` позначених описових фраз. Це запасний варіант, а не основний.

## Публікація

Файли лежать пласко, без підпапок, — їх можна перетягнути в репозиторій усі разом.
Далі Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`.

## Застереження

Переліки формулювань — заготовка, а не медичний стандарт. Перед використанням
у роботі лікар має вичитати їх і привести до прийнятих у закладі.
